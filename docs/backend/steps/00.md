**Vazifalar**
- [ ] `package.json`, `tsconfig.json`, `src/`, `.env.example`, `.gitignore`, `README.md`ni tekshir.
- [ ] Oldin yaratilgan `/api/health` endpointni aniqlab ol.
- [ ] `node -v`, `npm -v`, `npm install` natijalarini qayd et; npm network xatosi bo‘lsa yashirma.
- [ ] `npm run dev` va `npm run build`ni mavjud holatda sinab ko‘r.
