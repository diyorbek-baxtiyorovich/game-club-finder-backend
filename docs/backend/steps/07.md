## BOSQICH 07 — Clubs asosiy CRUD

**Fayllar:** `modules/clubs/club.routes.ts`, `.controller.ts`, `.service.ts`, `.repository.ts`, `.schema.ts` va `game_clubs` migration.

**Vazifalar**
- [ ] `game_clubs` jadvalini manba sxemaga mos yarat: `owner_id`, `name`, `slug`, `description`, `location`, `address`, `status`, h.k.
- [ ] `GET /api/v1/clubs`, `GET /api/v1/clubs/:id`, `POST /api/v1/clubs`, `PUT /api/v1/clubs/:id`, `DELETE /api/v1/clubs/:id` kontraktini yoz.
- [ ] Koordinatalarda `lng` va `lat` tartibini qat’iy saqla: `ST_MakePoint(lng, lat)`.
- [ ] Yangi club `pending` statusda yaratiladi; ommaviy API faqat `approved AND is_active` clubni ko‘rsatadi.
- [ ] `slug` unique; bir xil slug kelganda aniq xato.
- [ ] Owner ID token foydalanuvchisidan olinadi, body'dagi `ownerId`dan emas.
- [ ] O‘chirish uchun soft delete (`is_active`) siyosatini belgilab qo‘y; admin/egasi izlari yo‘qolmasin.
- [ ] Detail va list javoblari, page/limit default/max qiymatlarini bir xillashtir.

**Qabul mezonlari:** owner o‘z clubini yaratadi/tahrirlaydi; oddiy user va boshqa owner o‘zgartira olmaydi; `pending` club ommaga chiqmaydi.
