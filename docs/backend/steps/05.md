## BOSQICH 05 — Telegram Mini App autentifikatsiyasi

**Fayllar:** `integrations/telegram/verify-init-data.ts`, `modules/auth/*`.

**Vazifalar**
- [ ] `POST /api/v1/auth/telegram` uchun body schema: `initData` (string).
- [ ] Telegram WebApp `initData` imzosini bot token bilan serverda tekshir; `auth_date`ning eskirish vaqtini tekshir.
- [ ] Imzo va vaqt haqiqiy bo‘lgandan keyingina `telegram_id`dan foydalanuvchini top/yoki yarat (upsert).
- [ ] `user` roli default; frontenddan kelgan `role: admin` va `owner_id`ga ishonma.
- [ ] Noto‘g‘ri, eskirgan, o‘zgartirilgan `initData` → 401.
- [ ] Haqiqiy bot tokenni test kodiga kiritma, `initData`ni logga yozma.
- [ ] Lokal development uchun Telegram'ni chetlab o‘tadigan xavfli umumiy login endpoint qo‘shma. Agar mock kerak bo‘lsa, faqat test muhitida aniq himoyalangan usuldan foydalan.

**Qabul mezonlari:** yaroqli `initData` bilan foydalanuvchi yaratiladi/topiladi; fake ID va noto‘g‘ri imzo ishlamaydi; testlar bor.
