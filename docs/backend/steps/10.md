## BOSQICH 10 — PostGIS yordamida yaqin clublarni topish

**Fayllar:** `modules/discovery/*`, GiST indeks migratsiyasi.

**Vazifalar**
- [ ] `GET /api/v1/clubs/nearby?lat=...&lng=...&radius=5000&page=1&limit=20`.
- [ ] `lat` [-90,90], `lng` [-180,180], radius va limitni validatsiya qil; radius o‘lchovi **metr**.
- [ ] `location GEOGRAPHY(POINT,4326)` va `GIST(location)` indeksidan foydalan.
- [ ] `ST_DWithin` bilan radiusni filtrla, `ST_Distance` bilan metrda eng yaqindan sarala.
- [ ] Har bir natijada `distanceMeters`, koordinata, nom, reyting, cover qaytsin.
- [ ] Koordinata ruxsati yo‘q bo‘lsa frontend shaharni qo‘lda tanlaydi; backend shahar bilan qidirishni qo‘llaydi.
- [ ] `nearby` statik route'ini `/:id` route'idan **oldin** e’lon qil.

**SQL yo‘nalishi (namuna, parametrlar tekshirilib uzatiladi):**

```sql
SELECT c.id, c.name, c.rating_avg,
       ST_Distance(
         c.location,
         ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography
       ) AS distance_meters
FROM game_clubs AS c
WHERE c.status = 'approved' AND c.is_active = TRUE
  AND ST_DWithin(
    c.location,
    ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography,
    $3
  )
ORDER BY distance_meters ASC, c.id ASC
LIMIT $4 OFFSET $5;
-- $1=lng, $2=lat, $3=radiusMeters, $4=limit, $5=offset
```

**Qabul mezonlari:** 1km/5km/10km filtrlari mantiqan to‘g‘ri; koordinatalar adashmagan; faqat approved clublar keladi; noto‘g‘ri koordinata 400.
