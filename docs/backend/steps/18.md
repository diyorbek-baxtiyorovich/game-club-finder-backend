## BOSQICH 18 — Production / DevOps

**Manbada:** Docker, Nginx, GitHub Actions, Redis, monitoring ko‘rsatilgan. Biroq manbadagi Compose va CI misollari Python backend uchun yozilgan va production security uchun to‘liq emas.

**Vazifalar**
- [ ] Node.js uchun multi-stage Dockerfile (`devDependencies` final imagega tushmasin), `.dockerignore`.
- [ ] DB/PostGIS va backend uchun Compose; Redis faqat haqiqatan kerak bo‘lsa. Volume ma’lumotni saqlab qolsin.
- [ ] Environment/secrets'ni image yoki repo ichiga joylashtirma; runtime'da uzat.
- [ ] Health/readiness, server graceful shutdown, Pool.close.
- [ ] Nginx yoki platforma proxy, HTTPS, domen va CORS ishlab chiqarish originiga mos.
- [ ] CI: `npm ci` → lint/typecheck → test → build → image; production deploy faqat tegishli ruxsat va tasdiq bilan.
- [ ] Database migration deploy ketma-ketligi va rollback rejasi.
- [ ] PostgreSQL backup, restore sinovi, monitoring/error tracking, log retention.
- [ ] Eng kam huquqli DB account; security headers, rate limit, bot token aylantirish rejasi.

**Qabul mezonlari:** noldan boshqa muhitda ko‘tariladi; TLS bor; sirlar repo'da yo‘q; backupdan tiklash sinovdan o‘tgan; deploy nazoratli.
