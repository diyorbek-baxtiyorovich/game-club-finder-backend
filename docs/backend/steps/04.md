## BOSQICH 04 — Users bazasi va Games katalogi

**Fayllar:** `modules/users/*`, `modules/catalogs/*`, games migratsiyasi va seed.

**Vazifalar**
- [ ] `users` uchun repository/service asoslarini yoz; `telegram_id` unique va bigint ekanini hisobga ol.
- [ ] `games` jadvalini yarat va asosiy o‘yinlarni seed qil (`cs2`, `dota2`, `valorant`, `lol`, `gta5`).
- [ ] `GET /api/v1/games`, `GET /api/v1/games/popular` endpointlarini yoz.
- [ ] `GET /api/v1/users/me` endpointining kontraktini belgilab qo‘y, lekin access token ishlamaguncha uni ommaga ochma.
- [ ] Katalog seed qayta ishlaganda dublikat ko‘payib ketmasin (`slug` unique/upsert).

**Qabul mezonlari:** games ro‘yxati qaytadi, seed takrorlansa ham dublikat chiqmaydi, TypeScript build o‘tadi.
