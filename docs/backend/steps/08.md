## BOSQICH 08 — Club ichki ma’lumotlari

**Fayllar:** `clubs` ichidagi service/repository/schema qismlari; jadvallar: `club_equipment`, `club_features`, `club_pricing`, `club_images`, `club_games`.

**Vazifalar**
- [ ] Qaram jadvallarni to‘g‘ri migration tartibida yarat: avval `games`, keyin `club_games`.
- [ ] Club narxlari (oddiy/VIP/konsol, chegirmalar), jihozlar (Hz, CPU, GPU, RAM), o‘yinlar, xizmatlar, xona turlarini saqla.
- [ ] Ish vaqti JSONB sxemasini belgilab, hafta kuni va yarim tundan oshadigan ish vaqtini tekshir.
- [ ] Club yaratish/tahrirlashda bir nechta jadval birga o‘zgarsa **transaction** ishlat (`pg`da bir transaction ichida bitta client).
- [ ] `GET /api/v1/clubs/:id` frontend profilini to‘ldira oladigan, lekin keraksiz og‘ir bo‘lmagan response qaytarsin.
- [ ] Yaroqsiz narx (manfiy), cheklovdan tashqari Hz, noto‘g‘ri o‘yin ID tekshirilsin.

**Qabul mezonlari:** clubning to‘liq profili keladi; bittasi xato bo‘lsa transaction butun o‘zgarishni bekor qiladi; boshqa egaga tahrirlash man etiladi.
