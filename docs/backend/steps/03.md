## BOSQICH 03 — PostgreSQL + PostGIS va migration

**Fayllar:** `src/config/database.ts`, `database/migrations/*`, migratsiya skriptlari, `.env.example`.

**Vazifalar**
- [ ] PostgreSQL/PostGIS mavjudligini tekshir; lokal DB yarat.
- [ ] `pg.Pool` yarat; bitta central Pool bo‘lsin, connection cleanup va server shutdownni ko‘zda tut.
- [ ] `node-pg-migrate` sozla; migratsiya fayllari versiyalanib Git'da saqlansin.
- [ ] Birinchi migration: `CREATE EXTENSION IF NOT EXISTS postgis;` (DB huquqi yetmasa yo‘lini hujjatlashtir).
- [ ] `users` bazaviy jadvali migrationini qo‘sh.
- [ ] DB `SELECT 1` va PostGIS `SELECT PostGIS_Version()` bilan ishlashini tekshir.
- [ ] Database xatolarini foydalanuvchiga SQL/secret chiqarib yubormasdan qaytar.

**Qabul mezonlari:** yangi bo‘sh bazada barcha mavjud migration ketma-ket ishlaydi; health ishlaydi; `pg` ulanishi testdan o‘tadi.

> **Esda tut:** migratsiya keyin o‘zgartirilmaydi — yangi o‘zgarishga yangi migration. Production bazani `drop` qilib qaytadan yaratish mumkin emas.
