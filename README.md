# GameClubFinder — ketma-ket Codex to‘plami

Bu paketdagi `AGENTS.md` va `docs/backend/` papkasini mavjud Node.js backend loyihasiga joylashtiring.

**Har bir bosqich uchun faqat ikki fayl:**
- `docs/backend/PROGRESS.md`
- `docs/backend/steps/XX.md`

**Birinchi vazifa uchun Codex xabari:**

```text
AGENTS.md qoidalariga amal qil.
docs/backend/PROGRESS.md va docs/backend/steps/00.md fayllarini o‘qi.
Faqat BOSQICH 00 ni bajar, qabul mezonlari bo‘yicha tekshir.
Natijalarni PROGRESS.md'ga yoz va to‘xta. Keyingisiga o‘tma.
```

Davomini `docs/backend/START_HERE.md`dan o‘qing.
